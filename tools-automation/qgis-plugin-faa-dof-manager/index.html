FAA DOF Manager

Import, manage and convert FAA Digital Obstacle File data using QGIS and a PostGIS database.

Python  ·  PyQGIS  ·  QGIS ·  PostgreSQL  ·  PostGIS

The problem

Aeronautical obstacle data can be provided in different formats: CSV, DAT files, textual information (NOTAM, AIP). Those data need to be imported, maintained and stored to support further analysis and data management. Working with records from the FAA Digital Obstacle File (DOF) can involve repetitive data preparation and manual database operations.

The solution

FAA DOF Manager is a QGIS plugin that connects obstacle data workflows with a PostgreSQL database using PostGIS. It supports importing FAA DOF data, inserting individual obstacle records and updating existing records directly from QGIS.
